计费与机制

从授权到聊天，三步。

用 DeepSeek 账号登录授权，或填自己的 API Key；要历史就顺手导入，不要也能直接聊。聊天请求直连 api.deepseek.com，不经过本项目的中转服务器。

  1. 01

    授权账号，或填 API Key

    登录在 chat.deepseek.com 官方页面完成，App 不接触密码；授权 token 只存本机，也可以只填 API Key。

  2. 02

    导入历史（可跳过）

    登录后 App 拉取官方导出包，先给差异预览；不导入历史也能直接开始聊天。

  3. 03

    开始聊天

    请求直连 api.deepseek.com，按你账号的 API 用量计费；本项目不加价、不代收、不做中转。

历史导入
